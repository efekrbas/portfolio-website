## The Hidden Danger in CI/CD Processes: PPE
In software development processes, Continuous Integration and Continuous Deployment (CI/CD) pipelines are the most critical bridge for moving code to production. However, the security of this bridge is often overlooked. Poisoned Pipeline Execution (PPE) is a dangerous vulnerability that allows attackers to inject malicious commands into CI/CD pipeline configuration files (e.g., .gitlab-ci.yml, Jenkinsfile) to compromise build servers and, consequently, the production environment.

## Attack Scenario and Analysis
In my article, I demonstrated with practical examples how an attacker with low privileges submits a Pull Request (PR) to a repository, poisons the pipeline during the automated testing phase of this PR, and gains access to privileged environments. Leaking environment variables is one of the most common consequences of PPE.
