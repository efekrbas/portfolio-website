A full-stack web platform designed to help candidates prepare for public sector clerkship (kâtiplik) exams by offering tailored typing practice, real-time analytics, and realistic exam simulations.

### Key Features

- **F/Q Keyboard Courses**: Step-by-step 10-finger touch-typing modules supporting both Turkish F and Q keyboard layouts.
- **Exam Simulations & Speed Tests**: Timed typing challenges mimicking official clerkship exam constraints to measure WPM (words per minute) and accuracy.
- **Key-Level Analytics**: Detailed tracking algorithms to detect latency, frequent typos, and generate personalized drills for weak keys.
- **Activity Tracking & Leaderboards**: Progress dashboards logging streaks, test history, and competitive ranking among candidates.

### Tech Stack
Next.js, TypeScript, Tailwind CSS, Supabase (PostgreSQL, Auth, Realtime)

### Role & Impact
Co-developed the application architecture, implemented responsive UI components, and integrated state management for real-time keystroke tracking and backend data persistence.
