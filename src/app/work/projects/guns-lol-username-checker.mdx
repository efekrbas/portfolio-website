## Guns.lol Automatic Username Checker

With this tool I developed to detect available usernames on the Guns.lol platform, I completely automated the manual trial-and-error process.

**Key Features of the Project:**
- **Asynchronous HTTP Requests:** Uses a multithreading/asynchronous architecture for fast scanning.
- **Rate Limit Handling:** Includes an automatic wait and retry mechanism against rate limits encountered in requests made to the API or web services.
- **Performance:** Works at high speed and can test thousands of combinations in seconds.
