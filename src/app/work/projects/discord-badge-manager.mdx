## Discord Badge Manager

A modern Web and Desktop application designed to automatically and easily manage your HypeSquad houses (Bravery, Brilliance, Balance) and Legacy badge on Discord accounts.

**Key Features of the Project:**
- **Web & Desktop Support:** Use it directly in your browser or install it securely on your PC.
- **Secure Login:** The desktop app features a seamless one-click login via Discord without ever needing to manually handle tokens.
- **API Integration:** Assigns or switches badges within seconds by making direct requests to Discord's endpoints.
- **Premium UI:** Features a beautiful, fully responsive, and user-friendly interface.
