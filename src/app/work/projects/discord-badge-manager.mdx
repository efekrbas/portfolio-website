## Discord Badge Manager

A practical script designed to automatically and easily change or manage the Hypesquad house (House of Bravery, Brilliance, Balance) on Discord accounts.

**Key Features of the Project:**
- **Token-Based Authentication:** Securely connects to the Discord API using the user token.
- **API Integration:** Assigns houses within seconds by making direct requests to Discord's Hypesquad endpoints.
- **User-Friendly CLI:** Can be run quickly via the terminal to select the desired house.
